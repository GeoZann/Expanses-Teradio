Τετράδιο εξόδων (PWA)

Ανεβάζεις ΟΛΟΚΛΗΡΟ τον φάκελο σε HTTPS hosting (GitHub Pages, cPanel, Netlify, Cloudflare Pages).
Ανοίγεις το link στο κινητό και επιλέγεις "Εγκατάσταση εφαρμογής" / "Προσθήκη στην αρχική οθόνη".
Αν αλλάξεις αρχεία, άλλαξε το CACHE = "tetradio-v1" στο sw.js (π.χ. v2) για να ενημερωθούν οι συσκευές.
Τα δεδομένα μένουν στη συσκευή (localStorage).

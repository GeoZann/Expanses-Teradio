# Τετράδιο εξόδων

Προσωπική εφαρμογή για έσοδα, έξοδα και budget. Δουλεύει στο κινητό σαν κανονική εφαρμογή (PWA), συγχρονίζεται με λογαριασμό Google και διαβάζει απευθείας τα αρχεία κινήσεων των τραπεζών.

**Άνοιγμα:** https://geozann.github.io/Expanses-Teradio/

## Τι κάνει

- **Σύνοψη μήνα**: έσοδα, έξοδα, υπόλοιπο, ημερήσιο γράφημα και ανάλυση ανά κατηγορία.
- **Κινήσεις**: χειροκίνητη καταχώριση, με επιλογή αν πληρώθηκε με μετρητά ή κάρτα.
- **Budget**: όριο ανά κατηγορία και πόσο έχει μείνει.
- **Χρήματα**: υπόλοιπο κάθε τράπεζας, μετρητά και το σύνολο.
- **Εισαγωγή αρχείων τράπεζας**: προεπισκόπηση πριν την αποθήκευση, προτεινόμενες κατηγορίες, χωρίς διπλοεγγραφές.
- **Συγχρονισμός**: σύνδεση με Google, τα δεδομένα στο Firestore, και λειτουργία χωρίς ίντερνετ.

## Υποστηριζόμενες τράπεζες

| Τράπεζα | Αρχείο |
|---|---|
| Alpha Bank | CSV κινήσεων λογαριασμού |
| Πειραιώς | Excel κινήσεων λογαριασμού |
| Revolut | CSV statement |

Υποστηρίζονται και τα αρχεία κάρτας της Alpha και της Πειραιώς, που όμως δεν περιέχουν έσοδα.

Στο Android, όταν η εφαρμογή είναι εγκατεστημένη, ανοίγεις το αρχείο και πατάς **Κοινοποίηση → Τετράδιο**. Αλλιώς πατάς **Επιλογή αρχείου** στην καρτέλα Κινήσεις.

### Πώς ξεχωρίζουν οι κινήσεις

- **Διπλοεγγραφές**: κάθε κίνηση παίρνει ένα σταθερό κλειδί από τα στοιχεία της, οπότε το ίδιο αρχείο μπορεί να ανέβει ξανά χωρίς πρόβλημα.
- **Μεταφορές**: μεταφορές ανάμεσα στους λογαριασμούς σου δεν μετράνε ως έσοδο ή έξοδο. Αναγνωρίζονται από τη λέξη (μεταφορά, έμβασμα, top-up) και από το ζευγάρι ίδιου ποσού σε δύο τράπεζες μέσα σε 3 ημέρες.
- **Αναλήψεις**: μεταφέρουν χρήματα από την τράπεζα στα μετρητά.
- **Κατηγορίες**: όταν αλλάζεις την κατηγορία ενός καταστήματος, η εφαρμογή τη θυμάται για τις επόμενες φορές.

## Εγκατάσταση στο κινητό

1. Άνοιξε το link στον Chrome (Android) ή στο Safari (iPhone).
2. Επίλεξε **Εγκατάσταση εφαρμογής** ή **Προσθήκη στην αρχική οθόνη**.
3. Πάτα **Σύνδεση με Google** για να συγχρονίζονται τα δεδομένα σε όλες τις συσκευές.

## Αρχεία

| Αρχείο | Ρόλος |
|---|---|
| `index.html` | Η εφαρμογή: εμφάνιση, καρτέλες, προεπισκόπηση εισαγωγής |
| `import.js` | Ανάγνωση αρχείων τραπεζών και επεξεργασία (διπλοεγγραφές, κατηγορίες, μεταφορές) |
| `cloud.js` | Σύνδεση Google και συγχρονισμός με Firestore |
| `sw.js` | Service worker: λειτουργία χωρίς ίντερνετ και λήψη κοινοποιημένων αρχείων |
| `manifest.webmanifest` | Όνομα, εικονίδια και share target της εφαρμογής |

Δεν χρειάζεται build. Κάθε αρχείο σερβίρεται όπως είναι.

### Δεδομένα στο Firestore

```
users/{uid}/tx/{id}          μία κίνηση ανά έγγραφο
users/{uid}/meta/settings    budget, κανόνες κατηγοριών, υπόλοιπα, μετρητά
```

Οι κανόνες ασφαλείας επιτρέπουν σε κάθε χρήστη να διαβάζει και να γράφει μόνο τα δικά του:

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{uid}/{document=**} {
      allow read, write: if request.auth != null && request.auth.uid == uid;
    }
  }
}
```

## Ανάπτυξη

Τοπικά:

```bash
python -m http.server 8765
```

και άνοιγμα στο http://localhost:8765.

Σε κάθε νέα έκδοση άλλαξε το `CACHE` στο `sw.js` (π.χ. `tetradio-v11` → `tetradio-v12`), για να πάρουν οι συσκευές τα νέα αρχεία. Το GitHub Pages δημοσιεύει αυτόματα ό,τι ανεβαίνει στο `main`.

Για νέα τράπεζα προστίθεται μια πηγή στη λίστα `SOURCES` του `import.js`. Η πηγή αναγνωρίζει το αρχείο από τις στήλες του και επιστρέφει κινήσεις στην κοινή μορφή `{d, a, n, c, uid}`.
